# CRM Chayhana

Next.js frontend CRM. Ma'lumotlar hozircha brauzer `localStorage` ichida saqlanadi.

## Ishga tushirish

```bash
npm install
npm run dev
```

## Qo'shilgan qismlar

- Firmalar ro'yxati va firma ichidagi xaridlar tarixi
- To'langan/to'lanmagan holati va qarzdorlik hisoblari
- Mahsulot qo'shishda QR code maydoni
- Omborga mahsulot qabul qilishda QR code orqali topish
